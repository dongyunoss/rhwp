# 검증 결과 상태 정정

현재 `native/`, `sample16/` 및 `sample16-pixel-contract.json`은 실제 실행에서
측정한 이전 결과다. 해당 Native 실행 파일은 공유 Cargo target에서 리베이스 전
worktree의 차트 라이브러리를 재사용한 것이 확인됐다. 따라서 TSV의 값이나 384쪽
픽셀 결과를 **현재 소스의 최종 통과로 인정하지 않는다.** WASM 의존성은 별도로
확인 중이다. 현재 소스의 모든 workspace 의존성을 다시 빌드한 뒤 두 범위의 전쪽과
sample16 정수 픽셀 검증을 다시 실행하고 이 경로를 갱신한다.

차트 원본 `incoming-124`의 SVG에서 이전 의존성은 회색 `#8c8c8c`·선 두께 0.75를
사용하고 현재 소스의 차트 renderer는 `#868686`·선 두께 1을 사용한다. 이 차이를
실행 파일의 실제 SVG에서 확인했다. 이전 결과를 삭제하거나 기대값을 낮춰 통과로
바꾸지 않는다.

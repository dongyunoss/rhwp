# 검증 결과 상태 정정

`native/`와 `original-native-comparison.json`은 현재 차트 의존성을 명시적으로
재빌드한 Native 실행 파일로 다시 측정한 결과다. 기존 범위 67건·956쪽에서
0.1%p 이상 하락, 90% 미만 및 페이지 누락이 없다.

`sample16/`과 `sample16-pixel-contract.json`은 이전 의존성으로 측정한 결과이므로
**현재 소스의 최종 통과로 인정하지 않는다.** sample16 Native 192쪽은 새 실행으로
정수 픽셀 검사를 통과했으며, WASM을 포함한 전쪽 검사가 완료되면 해당 경로를 갱신한다.
기존 WASM 일부는 이전 수치 대비 0.1%p 이상 하락해 원인을 조사 중이다.

차트 원본 `incoming-124`의 SVG에서 이전 의존성은 회색 `#8c8c8c`·선 두께 0.75를
사용하고 현재 소스의 차트 renderer는 `#868686`·선 두께 1을 사용한다. 이 차이를
실행 파일의 실제 SVG에서 확인했다. 이전 결과를 삭제하거나 기대값을 낮춰 통과로
바꾸지 않는다.

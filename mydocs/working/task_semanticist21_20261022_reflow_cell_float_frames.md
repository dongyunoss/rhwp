# 재조판 셀의 부동 표 원점과 실제 점유

## 범위와 선행 증거

현재 45개 PR 통합 범위를 유지한다. 행정업무편람 개선과 사양 설명본·정오표 변경은
다른 PR의 작업이므로 제외한다. TABLE 값 2/CELL/RowBreak의 셀 내부 글줄 나눔
정정은 검토에 참고한다. 현재 반례의 표 속성은 NONE이다.

전 단계 1853~1866은 동일한 원본의 개별 속성만 바꾸고 실제 한컴 2020 Print와
Native121을 대조했다. 복제 ID·셀의 구역/단 정의는 Print 표 경계를 바꾸지 않았다.
안쪽 표가 글자처럼 취급이면 raw 99.09172%지만, 원래의 부동 표는 47.35546%다.
99% 쪽도 안쪽 오른쪽 괘선 차이가 있어 시각 완료로 보지 않았다.

선행 문단에 실제 텍스트를 넣은 대조에서 flowWithText=0/1의 Print 경계가 달라졌다.
이 값은 Task #1282 Stage 10/11의 실측대로 쪽 영역 안으로 제한(bit 13)이다.
이름을 글과 함께 이동으로 직역해 새 정책을 정하지 않는다.

## 원인 추적과 현재 가설

기존 reflow_block_table_host_occupied_height는 NO_LS 빈 자리차지 표 호스트의
줄과 개체를 합산하지 않고 합집합으로 센다. 다만 제한이 켜진 host만 대상이며,
HeightMeasurer의 여러 셀 경로는 셀 전체 all_no_ls도 요구한다. 현재 반례는
저장된 선행 글줄 뒤에 NO_LS host가 있어 일반 합산 경로로 빠진다.

현재 sequential_nested_cell_layout도 NO_LS가 하나라도 있으면 일반 계획을
반환하지 않는다. 측정은 unabsorbed_nested_tables_height/상세 줄 원장을 거치고,
배치는 reflow_nested_table_origin 뒤 별도 앵커·높이 선택을 거친다. 공통 helper를
호출한다는 이름만으로 소유가 일치한다고 판정하지 않는다.

새 규칙은 실제 저장 줄의 사다리를 전면 폐기하지 않고 재조판을 소유하는 host에서
필요한 줄/개체 원점과 물리 점유를 같은 결과로 발행해야 한다. 빈 글줄, 보이는 글자,
부동 개체의 flow 전진은 구분한다. 제한 off/true, 선행 텍스트 유무와 자식 높이를
각각 독립 Print로 대조한 뒤 수식과 적용 조건을 정한다. 특정 원본 ID·고정 px·
문서별 좌표 보정 또는 출력 숨김으로 해결하지 않는다.

전체 PR 준비 완료·전체 Rust 통과·fresh WASM 통과로 보고하지 않는다.

`float_placement/reflow_block_cell.rs`가 저장된 선행 글줄과 NO_LS 빈 표 호스트의
문단 원점·줄 전진량·개체 원점·부모 흐름 하단을 발행한다. 행 측정과 상세 원장,

유지한다. 부모 흐름 높이를 줄인 뒤에는 자식이 부모 셀의 짧은 viewport를 받아
`inferred_viewport_split`에서 다시 잘렸다. 실제 CLI의 1885 로그로 확인한 이

## 새 쪽 경계 반례: 자식 소유와 부모 흐름은 아직 분리 미완료

1893 입력은 표준 A4의 본문 예산을 여백으로 줄이고, 독립 주소가 있는 자식 3행과
부모/자식 `pageBreak=CELL`을 사용한다. 제한 false/true의 독립 Print는 각각
job `b240828a-61d4-4a07-8265-56000449168b`,
`2a9510fd-71ed-47d4-8771-e03469328959`이며 모두 한컴 2020의 Print 2쪽이다.
입력 변경·해시는 1883 → 1890 → 1893의 각 입력 영수증에 연결한다.

중간 진단의 오류도 보존한다. 사용자 지정 용지의 1883 입력은 Print가 A4로 나와
그대로 같은 용지 대조 근거로 쓰지 않았다. 1890 입력은 셀의 구역/단 정의 복사본을
제거하며 빈 `<hp:ctrl/>` 3개를 남겼고, 한컴이 여는 중 오류로 종료했다. 빈 wrapper를
제거한 별도 1893 입력은 정상 Print됐다. 실패 입력·job을 덮어쓰거나 같은 파일로
성공한 것으로 바꾸어 기록하지 않는다.

| 제한 | 독립 Print | 보정 전 Native121 | 현재 Native124 | 판정 |
| --- | --- | --- | --- | --- |
| false | 2쪽, 다음 쪽에 자식 마지막 행 | 2쪽, raw 최저 34.32542% | 1쪽, 전쪽 측정 불가 | 현재 변경의 자식 소유 회귀. 먼저 보정한다. |
| true | 2쪽 | 2쪽, raw 최저 72.49731% | 2쪽, raw 최저 72.49731% | 기존 출력 차이가 남았다. 통과 아님. |

1897의 review·overlay에서 true의 첫 조각을 직접 판독했다. 1898은 독립 PDF의
표 경계·본문·쪽별 직접 래스터를 보존한다. false의 Print 첫 쪽에서는 부모 외곽은
짧게 닫히지만 자식 두 행이 그 밖으로 이어진다. 둘째 쪽에는 부모 외곽 없이 자식
마지막 행만 이어진다. true는 부모 외곽도 이어진다. 따라서 false의 부모 높이를
자식 높이로 늘리거나, 부모 흐름이 끝났다는 이유로 자식 원본 소유를 버리면 안 된다.

후속 공통 결과는 부모 흐름 점유와 자식 원본/물리 구간을 따로 발행해야 한다.
`MeasuredCell`·전체 fit·`CellUnit`/RowCut 예약·부분 배치가 같은 소유 구간을 소비하게
연결한다. 겹친 선행 글줄과 자식의 구간은 합산 대신 실제 원점의 합집합으로 예산을
정하고, 부모 외곽의 종료와 자식 다음 쪽 소유를 함께 보호한다. 새 반례를 피하려고
문서 ID·고정 좌표·단일 쪽수에 맞춘 조건을 추가하지 않는다.

위 쪽 경계 반례·괘선 차이·fresh WASM 등 필수 항목이 남아 있어 PR 생성·승인·통합은
보류한다. 이 상태를 완료나 별도 이슈 이관으로 대신하지 않고 현재 브랜치에서 계속 보정한다.
